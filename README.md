# 📌 Python String DSA Programs

## 📂 Folder / File Structure


| File Name                             | Description                                                                                              |
| ------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| `1_0_reverse_string_using_slicing.py` | Reverses a string using Python slicing (`[::-1]`). This is the **shortest and most efficient** approach. |
| `1_1_reverse_string_using_loop.py`    | Reverses a string using **loop-based logic** without slicing, helpful for **interview explanation**.     |
| `2_reverse_word.py`                   | Reverses the **order of words** in a sentence while keeping each word intact.                            |
| `2_1_reverse_word.py`                 | Alternative implementation of word reversal using **manual loop logic**.                                 |
| `3_0_palindrome.py`                   | Checks whether a string is a **palindrome** using slicing technique.                                     |
| `3_1_palindrome.py`                   | Checks palindrome using **two-pointer / loop-based approach** (space optimized).                         |
| `4_0_anagram.py`                      | Checks if two strings are **anagrams** using **sorting method**.                                         |
| `4_1_anagram.py`                      | Checks anagram using **character frequency (dictionary)** for better performance.                        |
| `5_non_repeating_character.py`        | Finds the **first non-repeating character** in a string using frequency count.                           |
| `6_count_vowels_and_constant.py`      | Counts the number of **vowels and consonants** in a given string.                                        |
| `7_longest_common_prefix.py`          | Finds the **longest common prefix** among a list of strings.                                             |
| `8_remove_duplicates.py`              | Removes duplicate characters from a string **without using extra data structures**.                      |
| `8_1_remove_duplicates_using_set.py`  | Removes duplicate characters using a **set** while preserving original order.                            |
| `9_string_rotation.py`                | Checks whether one string is a **rotation of another** using concatenation logic.                        |
| `README.md`                           | Documentation explaining repository purpose, structure, and usage.                                       |
